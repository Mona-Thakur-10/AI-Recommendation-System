# AI Recommendation System

## Description
This project implements a simple recommendation system based on user skills and interests.
The system compares user-provided skills with predefined career roles and recommends the most suitable roles based on matching scores.

## Features

* User skill input
* Skill matching logic
* Career recommendation
* Top 3 recommendations

## Technologies Used

* Python

## How to Run

1. Open terminal in project folder.
2. Run the file:

python recommender.py

3. Enter your skills separated by commas.
4. View recommended career paths.
